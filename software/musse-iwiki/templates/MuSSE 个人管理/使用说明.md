# 使用说明

## 数据在哪里

- 所有任务、日程、长期目标、进度和快捷记录都保存在 iWiki。
- 本目录中的文档是人工可读的 Markdown 模板，不是另一套数据库。
- 小智机器人只通过 MCP 读写这些文档；没有本地持久化回退。

## 文档结构

```text
MuSSE 个人管理/
  使用说明
  任务总表
  长期目标索引
  长期目标/
    G-001
  快捷笔记
  历史归档
```

## 编辑规则

1. **任务状态只写在任务总表**。目标文档只引用任务 ID。
2. 任务 ID 必须稳定且唯一；不要手工复用已归档任务的 ID。
3. 日期使用 `YYYY-MM-DD`，时间使用 `HH:mm`（北京时间）。
4. 只有截止日期时，该日 23:59:59 之后才算逾期。
5. 已完成或已归档的任务不算逾期。
6. 历史归档不等于删除文档。

## 机器人能力

- 查询今天、未来 N 天、逾期任务。
- 创建、更新、完成、恢复、归档任务。
- 查询目标进度（按任务完成数计算），追加进度说明。
- 创建与查询快捷笔记。

机器人不会删除文档；写入前会读取当前内容，检测到变化时拒绝盲目覆盖。
