## 二、本机验证

以上三篇均保存成功后，从之前的 Windows PowerShell 进入 \`software/musse-iwiki\` 目录：

\`\`\`powershell
git pull
node --test tests/probe-goal-notes.test.mjs
node tools/probe-goal-notes.mjs
node tools/probe-goal-notes.mjs --live
\`\`\`

第四条命令会要求：
1. 输入文档 A 的 \`page-...\` ID；
2. 输入文档 B 的 \`page-...\` ID；
3. 输入文档 C 的 \`page-...\` ID；
4. 输入大写 \`YES\` 以批准最多三次 \`read_doc\`，**零写入**。

它只通过当前本机已有私人配置连接官方 iWiki MCP，在内存中按现有 \`TaskService\` 计算完成率、读取笔记数量。**输出仅含统计数字**，不含 Token、正文、笔记文本或实际文档 ID。终端交互过程会回显 ID，因此不要共享完整终端截图；仅复制两个 \`SAFE_GOAL_NOTES_SUMMARY\` 标记之间的 JSON。
