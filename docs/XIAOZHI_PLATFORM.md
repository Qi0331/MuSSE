## 二、已知固件与服务架构

- **设备端**：ESP32-S3 上的小智固件负责唤醒、音频采集/编解码、网络协议、播放、界面/LED、部分设备配置（NVS）；它不是个人待办、长期进度数据库，也没有在芯片上本地运行大语言模型的证据。
- **服务端**：官方平台为智能体配置和云端模型服务入口；历史对话、用户记忆和上传知识库等由平台提供管理功能，但实际后端数据库类型、地域、留存、导出、删改和普通账号可用范围仍需查官方政策与功能验证。
- **定制层**：未来 MuSSE 的任务数据、到期调度、重试、完成状态、长期追踪和管理页面需另行选择可靠服务或自建；不能将一次自然语言承诺、记忆条目或知识库文档当成已经设置的提醒。
- **云端 MCP 扩展**：控制台展示面向外部程序的工具接入点，可作为未来 MuSSE 业务工具的候选集成方式；是否支持持续在线、主动通知、鉴权/生命周期等需要单独验证。它与设备端 `McpServer` 的 MCP 工具注册不是同一个接口层。

## 三、v2.5.2 设备端显示接口复用

锁定上游源码参考：[`main/device_state.h`](https://github.com/78/xiaozhi-esp32/blob/49b4380b3faa0ceadd28a3e78aaf0f311c46c57e/main/device_state.h)、[`main/device_state_machine.h`](https://github.com/78/xiaozhi-esp32/blob/49b4380b3faa0ceadd28a3e78aaf0f311c46c57e/main/device_state_machine.h)、[`main/application.cc`](https://github.com/78/xiaozhi-esp32/blob/49b4380b3faa0ceadd28a3e78aaf0f311c46c57e/main/application.cc)、[`main/led/single_led.cc`](https://github.com/78/xiaozhi-esp32/blob/49b4380b3faa0ceadd28a3e78aaf0f311c46c57e/main/led/single_led.cc)、[`main/display/display.cc`](https://github.com/78/xiaozhi-esp32/blob/49b4380b3faa0ceadd28a3e78aaf0f311c46c57e/main/display/display.cc)。

- 已有 `Display::SetEmotion()` 以及网络 LLM emotion 相关消息处理；可复用其**情绪语义与事件**，不应将现有面向 OLED/LCD 的图片绘制等同于已支持 MuSSE 的 16×16 HT16K33A 或 WS2812B。
- 设备状态包含 Idle/Connecting/Listening/Speaking/FatalError 等，**没有** `kDeviceStateThinking`；Connecting 是连接过程，不能默认代表推理中。Thinking 表情需通过真实可核验的独立业务事件或仅作为离线测试状态。
- `DeviceStateMachine::AddStateChangeListener()` 在状态切换调用上下文执行；上游 `Application::HandleStateChangedEvent()` 在主事件循环调用 `Board::GetLed()->OnStateChanged()`，未来适配不能在同步回调里阻塞执行 256 LED 的刷新。
- `bread-compact-wifi` 使用单 LED 驱动，不是 16×16 物理矩阵驱动；必须保留逻辑坐标映射、双色/单色表现与可替换输出适配层。

## 四、阶段顺序（覆盖此前“立即重造独立表情系统”的建议）

1. **当前一轮**：由 Reasonix 在 Windows 本地只读对照 v2.5.2 的真实情绪/状态/动画接口，做能复用官方语义的 16×16 逻辑渲染、纯 C++ 单测、离线动态预览；明确哪一段是 MuSSE 专属代码。允许对隔离副本进行编译验证，不覆盖锁定的研究副本。
2. **硬件就绪后**：先按规范检查麦克风、功放/扬声器、OLED、供电和引脚，获得新的逐次授权后才可能烧录并测试语音闭环；本地编译不能冒充真机验证。
3. **未来 M2/M3/M4**：确定安全显示输出驱动，检查官方 MCP 扩展接入与数据管理，再决定与现有提醒事项服务同步，还是独立建立 MuSSE 的持久数据库/任务网页/调度。任何账号私有数据不直接放在公开仓库。

## 五、安全与未验证清单

- **未验证**：官方智能体绑定、实际语音会话、记忆写入与召回、知识库问答、MCP 工具注册/调用、定时/推送通知、云端编译兼容性。
- **禁止上传**：MCP 完整带 token 的 URL、账号令牌、登录会话、个人对话/记忆原文、原始用户截图、Flash 镜像/私有日志。
- 已有两种 LED 矩阵在电压、电流、实际像素映射核对之前继续**不接线、不上电**；本次只更新软件架构认识，不改变 USB 5V 长期有线供电、固定上游版本及硬件禁令。
