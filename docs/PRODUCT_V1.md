## 1. 目标和边界

打造能够在**电脑关机后仍通过手机/电脑访问**的独立 MuSSE 网页工作台，管理待办、长期目标和快捷笔记，并可经授权访问学院 iWiki。当前 **不做主动推送、后台定时提醒、自动播报、短信或通知调度**。截止日期、即将到期、逾期状态仅在用户打开网页或主动查询时计算展示。

优先开发软件产品 B+C，不因音频、OLED、新 RGB 灯板等硬件尚未到货而阻塞。当前不刷固件、不接线、不运行需要实物的测试。

## 2. V1 必做功能

- **待办事项**：创建、列表、编辑、完成、软删除/归档；名称、说明、截止时间、优先级、分类、状态；按日期/状态筛选、逾期标记。
- **长期目标**：目标与阶段/子任务关联、进度记录、阶段总结与历史变化。进度应根据明确规则生成或手动记录，不能无依据虚构百分比。
- **快捷记录**：新建和查看文字笔记，并可关联待办或目标。
- **网页**：移动端优先，同时适配电脑；待办、长期目标、日历/截止日期视图、知识库入口；基础登录和用户数据隔离。
- **知识库 B**：按学院 iWiki 已发布的 MCP/API 能力，提供私密文档搜索、读取及经明确授权的创建/编辑；不实现自己的完整文档协同编辑器。
- **小智预留接口**：设计可复用的任务创建/查询/更新工具接口，但设备语音真机调用、MCP 桥接可用性留待后续验证。

## 3. 存储和部署决定

- **结构化任务权威来源**：优先采用国产托管云数据库，当前首选腾讯云开发（CloudBase）的受控数据库；保存 tasks、goals、goal_tasks、notes、activity 等业务数据。实际选择文档库或关系型库，以实现简单性、权限隔离和平台实际能力为准，不预先同时建设两种。
- **长期知识权威来源**：学院 iWiki 的**我的知识库**；通过远程 MCP `https://ssemarket.cn/iwiki-api/mcp` 或其官方文档化 HTTP API 搜索、读写文档。任务可保存 iWiki 文档 ID/链接，但**不依赖 iWiki 文档搜索来执行全部任务状态管理**。
- **小智知识库（内测）**：可作为未来问答/检索辅助，不当作待办数据库或提醒执行器，不假设已和 iWiki 自动同步。
- **云端运行**：网页静态托管 + 托管数据库；仅对 iWiki Token 代理或必要业务逻辑使用小型云函数。无需自己维护长期在线的传统虚拟机；但电脑关机后可用依赖云平台和网络正常运行。
- **国内可用性**：优先中国大陆网络可用的国产方案；域名、ICP备案、服务地域、免费额度/费用、手机实测均在正式部署前核验，**不声称已经开通或上线**。
- 不再把 SQLite 或“全部数据存在 iWiki”视作默认架构。必要时可以按实际验证调整，避免无谓迁移。

## 4. 权限、真实接口和数据安全

- iWiki 的可读写 Token 能编辑拥有权限的文档、追加内容并支持版本历史；**不能通过 Token 删除文档**。在 MuSSE 中明确区分任务软删除和知识库文档删除。
- Token 只保存在服务端的秘密配置中；浏览器、固件和 Public GitHub 不得包含 Token。不给客户端通用的任意文档写入代理；写操作需鉴权、限定范围并检查用户确认。
- 软工集市的 `agent:chat`、`forum:read`、`forum:write` 与 iWiki 令牌不同，不是待办数据库。论坛写入等对外操作不属于 V1。
- 真正的 iWiki MCP 调用、小智 MCP 调用、腾讯云开通/付费/发布、个人账号数据写入须逐次获得授权；发布文档说明不等于完成接口兼容测试。
- 个人任务与笔记不进入 Public 仓库；使用用户专属空间与最小权限，支持导出/备份或恢复路径的基本设计。

## 5. 直接开发，不设独立 Mock 阶段

1. Reasonix 直接实现正式的移动端网页、任务/目标业务逻辑、云端存储接口和 iWiki 接口适配。需要等待密钥或云服务时，仅以极小的测试数据/本地适配保证开发可运行，**不要另建 Mock 平台或无限模拟测试**。
2. 最小必要验收：任务增改查、完成/归档、刷新后数据保持；目标与子任务关联正确；截止日期/时区展示正确；登录后数据隔离；服务不可用时不误报保存成功；iWiki 接口出错时安全回退、令牌不会泄露。
3. 完成可运行产品后针对实际问题修正。**不设人为测试数量目标，不无限重构、重复写适配层或因未到货硬件阻塞软件开发**。
4. 第一个开发交付物是 Windows 可本地启动和演示的**真实网页 + 真实任务逻辑**，包括精简 README/启动命令及必要检查；随后单独授权云端部署和真实 iWiki 接入。
