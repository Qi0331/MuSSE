# 创乐博 16×16 I²C LED 矩阵：实物调查（未接线）

## 正面和背面照片实证（2026-11-02）

团队现有的一块蓝色 PCB 上标有：
- **创乐博 / MAKEROBO**
- **I2C 16x16 LED Matrix Board for Raspberry Pi**
- 四针丝印顺序：**+5V / GND / SDA / SCL**

新增的**背面照片**显示两颗 Holtek（合泰）芯片，丝印均可辨认为 **HT16K33A**。两颗 16×8 LED 驱动器可组成 16×16 点阵，但具体映射仍需查原理图/实际验证。

由此可称其为 **16×16（256 个位置）的 I²C LED 矩阵模块**。用途写着 Raspberry Pi，但 I²C 是通用协议，**不能据此断言只支持树莓派，也不能据此保证 ESP32-S3 兼容**。

本仓库没有公开上传用户实物照片；如需要公开上传，应先确认照片没有个人信息。

## 电气风险

ESP32-S3 GPIO 是 3.3V 逻辑；`+5V` 的印字不自动说明 SDA/SCL 上拉电平。如果矩阵把 I²C 线上拉到 5V，则直接接 ESP32-S3 存在烧毁风险。

**安全门槛**：驱动芯片已确认，但仍须核对板卡电路/规格 → 核对电源与最大电流 → 判断 I²C 上拉电压 → 必要时使用 I²C 双向电平转换器，并选用可提供足够电流的 5V 供电。所有接线均应由实物、规格与经过审核的接线方案确认。

暂时**不要**接 `+5V`、`SDA`、`SCL` 到 ESP32-S3 进行试验。

## 已核对的通用原理参考（**非这块板的型号证据**）

- [乐鑫 ESP32-S3 GPIO 与供电设计](https://docs.espressif.com/projects/esp-hardware-design-guidelines/en/latest/esp32s3/schematic-checklist.html)：确认主控工作电压和引脚注意事项。
- [Grove HT16K33 驱动介绍](https://wiki.seeedstudio.com/cn/Grove-LED_Matrix_Driver-HT16K33/)：这是**别的模块**使用的驱动，不能据此宣称本板也是 HT16K33。
- [另一厂商 16×16 I²C 矩阵](https://www.meiyagroup.com.tw/product/41-%E6%A8%B9%E8%8E%93%E6%B4%BE-raspberry-pi-led-matrix-16x16-%E6%93%B4%E5%85%85%E6%9D%BF/)：说明 16×16 可能由多个驱动器组成，但不能照搬地址或像素布局。

已确定的芯片有官方原厂资料：[合泰 HT16K33A 产品页与数据手册](https://holtek.com.cn/page/vg/HT16K33A)，列出工作电压 **4.5–5.5V**、I²C 接口与单芯片 16×8 显示容量。**但仍未找到能确认对应此 MAKEROBO PCB 修订的原理图、I²C 地址/上拉设计、像素映射和整板耗电。**

芯片识别不是完成电气安全验证；目前仍需在确认板上有无 5V 上拉、供电余量之后才可联机。

## 2026-11-02 新购买的**另一种**矩阵：WS2812B 16×16 RGB（仅商品截图）

用户另购商品页面写着 **“5V可编程 256位 RGB 灯板 16×16 WS2812B”**，照片展示 16×16 方格与三芯线束。此为新的**可编程 RGB 单线灯珠矩阵**，并非本页上文已持有的 **创乐博 2×HT16K33A 的 I²C 矩阵**。新灯板未提供到手实物照片、电路、型号复核，不能宣称已验证 256 颗灯珠/走线/排列。

| 项目 | 已有创乐博矩阵 | 新买 WS2812B RGB 矩阵（待到货） |
| --- | --- | --- |
| 驱动原理 | 2×HT16K33A，I²C | WS2812B 单线时序协议，常需专用 RMT/SPI 输出驱动 |
| 控制信号 | SDA、SCL | DIN 单数据输入（具体焊盘与方向需对实物检查） |
| 电源 | 模块标 +5V，芯片要求 4.5–5.5V | 商品标 5V，真实额定电流未测 |
| 逻辑电平转换 | BSS138 I²C 双向模块为候选 | **不能默认用 BSS138 四路 I²C 模块**；应评估合适的 5V 供电单向缓冲器如 74AHCT/74HCT 类及兼容时序 |
| 功耗 | 未知，需要核对整板耗电 | 256 RGB 颗粒可能在高亮全白时形成**远大于 ESP32 开发板 5V 引脚可提供值**的电流需求；5V/3A 适配器标称值不足以证明可满载 |
| 像素映射 | 未测 | 排列/首像素位置/走线方向未测 |

建议在**硬件无关的 16×16 帧缓冲与状态表情层**先行开发，后续按安全及产品选择分别实现 HT16K33A 与 WS2812B 输出适配，避免软件架构被单一灯板锁死。当前未做任何新矩阵连接或通电。

## 本次增补的硬件风险参考

- 社区在 [Issue #11](https://github.com/Qi0331/MuSSE/issues/11) 提议对 HT16K33A 5V I²C 使用 BSS138 双向电平转换与共地；该建议有参考价值，但**板上实际 SDA/SCL 上拉电压、确切 I²C 地址、整板电流不能仅从评论确定**。
- 原有 I²C 模块数据线禁止在电平未核验时直连 3.3V GPIO；新 WS2812B 应核对 5V 供电电流、线束、输入/输出方向和数据电平后再上电。
- 原计划较小的 LED 驱动电流不能直接应用到 WS2812B 256 RGB 颗粒；需额定供电与亮度上限设计，避免发热、掉压、复位和线材过流。
