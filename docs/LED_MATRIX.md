# 创乐博 16×16 I²C LED 矩阵：实物调查（未接线）

## 照片实证（2026-11-02）

团队现有的一块蓝色 PCB 上标有：
- **创乐博 / MAKEROBO**
- **I2C 16x16 LED Matrix Board for Raspberry Pi**
- 四针丝印顺序：**+5V / GND / SDA / SCL**

由此可称其为 **16×16（256 个位置）的 I²C LED 矩阵模块**。用途写着 Raspberry Pi，但 I²C 是通用协议，**不能据此断言只支持树莓派，也不能据此保证 ESP32-S3 兼容**。

## 电气风险

ESP32-S3 GPIO 是 3.3V 逻辑；`+5V` 的印字不自动说明 SDA/SCL 上拉电平。如果矩阵把 I²C 线上拉到 5V，则直接接 ESP32-S3 存在烧毁风险。

**安全门槛**：找出驱动芯片和板卡电路/规格 → 核对电源与最大电流 → 判断 I²C 上拉电压 → 必要时使用 I²C 双向电平转换器，并选用可提供足够电流的 5V 供电。所有接线均应由实物、规格与经过审核的接线方案确认。

暂时**不要**接 `+5V`、`SDA`、`SCL` 到 ESP32-S3 进行试验。
