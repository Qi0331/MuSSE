## 二、已收到的矩阵照片可直接确认

- 板上印有「**创乐博 / MAKEROBOT**」。
- 有文字 `I2C 16x16 LED Matrix Board for Raspberry Pi`，可识别为 **16×16 点阵（256 个点位）**。
- 四针丝印依次为 `+5V`、`GND`、`SDA`、`SCL`。
- 仅有这张照片；**驱动 IC、PCB 修订、I²C 地址、是否集成电平转换、SDA/SCL 上拉到 3.3V 还是 5V、电流需求均无法可靠确定**。
- 尚未将照片作为附件提交到 GitHub。新 Agent 若需要查芯片，请请求团队提供**高清正反面**或厂商说明书，而不是猜测芯片型号。

### 电气风险与操作规则

1. **不得将矩阵 +5V 连接 ESP32-S3 的 3V3 引脚**，也不应从未知载流能力的 3V3 口试图驱动整块矩阵。
2. ESP32-S3 GPIO 是 3.3V 逻辑。除非找到可靠证据证明矩阵信号在 3.3V 范围内，否则**不得将可能上拉至 5V 的 SDA/SCL 直接连接 GPIO**。
3. 某些专为树莓派设计的模块用 5V 供电，却仍采用 3.3V I²C；因此不能未核验就断言“必需”或“不需要”电平转换器。
4. 驱动确认后才能决定 I²C 地址、代码/寄存器协议；不应套用其他 16×16 / HUB75 / WS2812 的库。
5. 如最终需要 5V 信号，应在确认电气连接方案并准备合适双向 I²C 电平转换器、电源后再进行测试。
6. 参见 [#8 矩阵调查](https://github.com/Qi0331/MuSSE/issues/8) → [#9 安全独立点亮](https://github.com/Qi0331/MuSSE/issues/9)。
