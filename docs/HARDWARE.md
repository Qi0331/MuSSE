## 现有 LED 矩阵的照片可确认什么？

- 丝印为 **“创乐博 MAKEROBO / I2C 16x16 LED Matrix Board for Raspberry Pi”**。
- 接口只有 **`+5V`、`GND`、`SDA`、`SCL`**；表明用 I²C 通信，标称 +5V 供电。
- 新增背面照片已识别 **两颗 Holtek HT16K33A**；官方芯片供电要求 **4.5–5.5V**。仍无法仅凭照片得知实际 I²C 地址、SDA/SCL 上拉电压、电流、像素映射；ESP32-S3 可通过电平转换等方式适配，但**尚未通过电气核验**。
- **安全状态**：不得接 ESP32 的 SDA/SCL 直到确定电平兼容性；若数据线被上拉到 5V，需正确的 I²C 双向电平转换电路。
- 另一面照片和芯片识别已经完成；现在重点在 PCB 实际上拉电路、供电能力和 I²C 地址。详见 [Issue #11](https://github.com/Qi0331/MuSSE/issues/11)。

## 安全规则

断电调整接线。ESP32-S3 的 IO 为 3.3V 逻辑，不能默认耐受 5V。没有规格书不能把 LED 矩阵的 `+5V` 接到 `3V3` 试运气，也不能在不知道 SDA/SCL 上拉电压时直连 GPIO。杜绝主控短路、错误供电和负载超额。功放输出不得连接 GPIO。
