# MuSSE 系统架构（仅草案）

```text
[ESP32-S3 实体端]
  INMP441 + MAX98357 + OLED + 按键 + 未来灯阵/旋钮
           │ 语音数据 / 设备命令
           ▼
[小智 AI 基础语音与连接服务]
           │ 经过确认的接口 / 设备工具
           ▼
[MuSSE 自定义服务 — 尚未实现]
  校园知识检索 | 快捷记录 | 长期记忆 | 任务调度
```

## 拟议职责

- **嵌入式设备端**：音频采集播放、联网、状态显示、本地按钮和灯阵控制。
- **小智基础服务**：复用现成的语音交互和设备控制能力，降低从零开发成本。
- **MuSSE 后端（未来）**：按授权做校园知识检索、持久化记录、记忆和提醒调度；不要将密钥直接写入公开固件。
