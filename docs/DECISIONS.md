## D-006 — 采用 USB 5V 长期有线桌面供电，暂不做电池

- **日期**：2026-11-02
- **状态**：已确认（覆盖当日早期“考虑 USB+电池双模式”的意向）
- **决定**：MuSSE 优先作为固定桌面机器人使用，使用可靠 USB 5V 电源；**当前不实现电池、充电、电池升压及自动切换系统**。正常开发仍使用已验证的主板 USB 连接。
- **理由**：无需移动需求，减少成本、电池充电热风险及复杂供电路径；有更多资源集中开发语音和表情。
- **边界**：用户图片中已购买带 14500 电池的供电模块，不意味着被选为正式电源；未经核验不得连接或充电。5V/3A 适配器为商品标称，不能推导整机够用。外部 5V/电脑 USB 反灌风险、外设电流仍待评估。
- **复查条件**：用户未来明确提出无线移动、供电瓶颈或实际功耗证据。

- **复查条件**：准确 SKU、到货实物、供电测试和最终选定主显示方式。

## D-013 — 采用 iWiki 单数据源与被动查询方案（覆盖原 V1 网页/CloudBase）

- **日期**：2026-11-03
- **状态**：用户已确认；取代 D-011 所描述的“独立网页 + CloudBase + 独立数据库” V1 实施方向（D-011 历史保留）

- **决定**：

  2. 小智仅通过 MCP 读取/创建/更新，被动响应；不开发独立网页、CloudBase、云数据库、主动提醒或推送。

- **已知证据**：iWiki 官方公告（Markdown、冲突合并、权限、Token 预留）；SSE_MARKET 平台 MCP 文档（MCP 2025-06-18、Streamable HTTP、Bearer PAT，但属于论坛工具）；`xiaozhi-client` npm 元数据/README。iWiki 具体工具名/参数/版本条件写入**未公开**。
- **风险**：桥接单点（Windows 关机即失效）、iWiki 工具契约未知、WYSIWYG 可能改格式、Token 与权限管理、无官方托管桥接。
