# MuSSE 当前项目状态（唯一权威）

- **最后更新**：2026-11-02
- **阶段**：M0 — 现有硬件的单板核验与基础实验
- **总体进度**：仓库基础文件已建立；已有部分硬件到货，但尚无硬件实测
- **代码状态**：目前只有项目管理、文档及基础检查脚本；没有 MuSSE 自研固件/后端
- **仓库**：[Qi0331/MuSSE](https://github.com/Qi0331/MuSSE)；默认分支 `main`；**Public（由团队确认保持）**

## 已确认的事实

- 团队已实际收到 ESP32-S3 N16R8、面包板、跳线、按钮、Type-C 线，以及印有 MAKEROBOT／创乐博的 16×16 I²C LED 矩阵（丝印 +5V/GND/SDA/SCL）；主控与矩阵均未核实供电/驱动。音频和 OLED 模块仍未到货，见 `HARDWARE.md`。
- 已定位小智公开仓库 `78/xiaozhi-esp32` 与 `v2.5.2` 的 `bread-compact-wifi` 候选固件；未确认实物匹配。
- 功能目标包括基础语音对话、OLED、按键，未来拟加入 LED 灯阵、扭动开关、校园信息检索、记录、记忆和提醒。
- GitHub 目录和 Agent 协作规则已提交。初次 GitHub Actions 文档检查已通过（提交 `1ec1c34`）；这**不代表**硬件、固件或业务功能通过测试。

## 当前开发策略

参见 [ROADMAP](ROADMAP.md)；顺序是 **板型与 USB 识别 → 最小串口程序 → 按钮输入**。与之并行的矩阵调查只核查驱动及电气兼容性；**未确认逻辑电平/供电前，不连接矩阵至 ESP32-S3**。小智语音闭环等麦克风、功放、喇叭及 OLED 到货再推进。

## 尚未验证（绝对不要标为完成）

- 尚未到货的 INMP441、MAX98357、扬声器、OLED 的真实板型、供电、I2S/I2C 地址与引脚。

- Windows 识别 USB 设备、烧录、联网、激活、麦克风、播放、对话的任何结果。
- 校园 API 的开放性、授权和后端实现。
- 组员是否已接受邀请、`main` 分支规则是否启用。

## 按顺序执行的下一步

1. **M0-01** 获取 ESP32-S3 实物正反面照片和排针丝印，核对产品描述。
2. **M0-02** 不接任何外围组件，单独 USB 连接 Windows 并记录设备管理器结果。
3. **M0-04（#7）** 完成最小串口程序与按钮输入；另一路调查矩阵 #8。
4. **M0-06（#9）** 仅在矩阵驱动、电平、供电全部核验后开展点亮演示（若必要电气器件缺失则等待）。
5. **M1（其他配件到货之后）** 完成 #3、#4：固件/接线审核与首次安全语音闭环。

## 当前阻塞

缺少 ESP32-S3 开发板实物正反面照片、矩阵驱动 IC 及 I²C 电平/供电说明；其他音频和 OLED 配件也尚未到货。不得将候选 GPIO 当作正式安全接线结论。

## 更新本文件的规则

真实测试应有 `TEST_LOG.md` 记录；更改技术方向应有 `DECISIONS.md`；每次状态改变应链接对应 Issue / PR。状态一旦变化须同步更新本文件，避免其变成过期资料。
