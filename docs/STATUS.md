# MuSSE 当前项目状态（唯一权威）

- **最后更新**：2026-11-02
- **阶段**：M0 — 仓库初始化与实体硬件核验
- **总体进度**：仓库基础文件已建立；尚无硬件实测

## 已确认的事实

- 团队已经购买一套标称 ESP32-S3 N16R8 的语音 DIY 组件，具体见 `HARDWARE.md`。
- 已定位小智公开仓库 `78/xiaozhi-esp32` 与 `v2.5.2` 的 `bread-compact-wifi` 候选固件；未确认实物匹配。
- 功能目标包括基础语音对话、OLED、按键，未来拟加入 LED 灯阵、扭动开关、校园信息检索、记录、记忆和提醒。
- GitHub 目录及 Agent 协作约定正在按初始化任务提交，不视为硬件开发进展。

## 尚未验证（绝对不要标为完成）

- 开发板厂商/PCB 修订/USB 接口与引脚标识。
- INMP441、MAX98357、OLED 的真实板型、供电、I2S/I2C 地址与引脚。
- Windows 识别 USB 设备、烧录、联网、激活、麦克风、播放、对话的任何结果。
- 校园 API 的开放性、授权和后端实现。
- 组员是否已接受邀请、`main` 分支规则是否启用。

## 按顺序执行的下一步

1. **M0-01** 获取 ESP32-S3 实物正反面照片和排针丝印，核对产品描述。
2. **M0-02** 在确认板型后，不接任何外围组件，单独 USB 连接 Windows 并记录设备管理器结果。
3. **M0-03** 检查所有模块引脚、电压与候选固件 GPIO 的对应关系，形成接线前核对表。
4. **M1-01（之后）** 审核固件版本、发布文件与烧录方法；安全接线并在授权下执行首次烧录。

## 当前阻塞

缺少实物高清照片，不能最终确认兼容性，更不能把候选 GPIO 当成可安全接线的结论。

## 更新本文件的规则

真实测试应有 `TEST_LOG.md` 记录；更改技术方向应有 `DECISIONS.md`；每次状态改变应链接对应 Issue / PR。状态一旦变化须同步更新本文件，避免其变成过期资料。
