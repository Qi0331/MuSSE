1. **CH343/芯片**：COM6 对应 USB VID 1A86:55D3；esptool v5.6.0 读得 ESP32-S3 rev v0.2、16 MB Flash、40 MHz 晶振，识别信息列出 8 MB PSRAM（未做运行时读写测试）。
